# 📊 Pesquisa de Satisfação

Este repositório contém a resolução da atividade prática **Agenda_08_DSI** para a disciplina de Desenvolvimento de Sistemas I (DSI) da ETEC.

---

## 📌 Descrição do Projeto

O programa realiza a coleta e a contagem de opiniões de uma pesquisa de atendimento ao cliente para a empresa TudoWeb. O sistema entrevista 50 clientes, solicitando nome, idade e nota de satisfação, contabilizando os resultados ao final.

---

## ✨ Destaques da Implementação

* **Estrutura de Repetição:** Uso do laço `for` configurado para iterar exatamente 50 vezes.
* **Estrutura de Decisão:** Validação das respostas utilizando comandos `if` e `elif` para contagem exata dos votos ("EXCELENTE" e "RUIM").

---

## 🛠️ Tecnologias Utilizadas

* **Python 3.x**

# 🚀 Como Executar o Projeto

Para executar o programa em sua máquina, siga os passos abaixo:

1. Certifique-se de ter o **Python** instalado em seu computador.
2. Abra o arquivo `pesquisa_satisfacao.py` em sua IDE de preferência (como o Visual Studio Code).
3. Execute o script no terminal para iniciar as entrevistas com os 50 clientes.
